Paddle Import

← back to Cairn

Pulls a route off PaddlePoints and turns it into a .gpx file you can download, then drag into your "Cairn GPX Routes" Drive folder yourself — same as you already do for manually-created routes.

1. Capture a route

Drag this button to your bookmarks bar once. On any PaddlePoints route page, click it, then click PaddlePoints' own "View" button — the route's data gets copied to your clipboard on its own. Then come back here (or switch to this tab) and paste it into the box below.

⛺ Cairn: Grab Route

This only watches requests already made by the page you're on — it doesn't add any new network calls of its own, and it stops working the moment you leave or refresh that page.

2. Paste it here

Either the clipboard text from step 1, or — if you'd rather do it by hand — Dev Tools (F12) → Network tab → click "View" on the route → click the admin-ajax.php request → Response tab → copy the full text.
